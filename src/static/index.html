Why we built this

Contracts are written to be skimmed past, not read

Auto-renewal clauses, one-sided indemnification, mandatory arbitration — the terms that matter most are usually the ones buried in dense legal language. This tool reads the whole document, pulls out what matters, and checks it against a bank of common risky clauses, so the fine print stops being invisible.
